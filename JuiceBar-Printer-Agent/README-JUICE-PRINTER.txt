================================================================
  SULTAN RESTAURANT - JUICE BAR DEDICATED PRINTER SETUP (v3.0)
================================================================

1. RIGHT-CLICK the downloaded ZIP file and click "Extract All..."
   onto Desktop or C:\SultanPrinter on the Juice Bar PC.
   (IMPORTANT: Do NOT run .bat files directly inside the ZIP window!)

2. Make sure the Juice Bar USB Thermal Printer is plugged into the Juice Bar PC
   and its Windows driver is installed.

3. Double-click "Start-JuiceBar-Printer.bat":
   - Opens the permanent Desktop GUI window!
   - Automatically detects ANY USB/Thermal printer on the PC (even newly installed drivers).
   - Click "Print Test Slip" inside the window to confirm printing.

4. Double-click "Install-AutoStart-On-Boot.bat" ONCE:
   - Automatically starts the Juice Bar Print Agent every morning on PC boot!

TROUBLESHOOTING:
- Double-click "Diagnose-JuiceBar-Printer.bat" to see ALL Windows printers,
  USB ports, driver names, and live connection check to http://192.168.1.10:5050.

Zero conflict guarantee:
- Kitchen orders print ONLY on the Kitchen printer (POS-80 on 192.168.1.10).
- Juice Bar orders (Hot Coffee & Tea, Ice Coffee, Mocktail, Ice Cream, Cold Drinks & Water)
  print ONLY on the Juice Bar USB printer!
